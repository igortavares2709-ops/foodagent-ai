# Security Policy

Este repositório usa somente dados fictícios. Não abra issues com chaves,
senhas, tokens, CPF, cartão ou dados pessoais.

Para relatar uma vulnerabilidade, use uma mensagem privada ao mantenedor no
GitHub. Inclua impacto, reprodução mínima e versão afetada, sem explorar dados
de terceiros.

Credenciais locais pertencem ao arquivo .env ignorado pelo Git. Revogue
imediatamente qualquer segredo publicado por engano.
