# Política fictícia de cancelamento

## Antes do preparo
O cancelamento pode ser simulado imediatamente quando o restaurante ainda não
iniciou o preparo. Nenhuma cobrança ou pedido real é alterado neste portfólio.

## Após o preparo
Quando o preparo já começou, a solicitação deve ser encaminhada para revisão
humana. O agente explica o motivo e registra somente uma simulação.
