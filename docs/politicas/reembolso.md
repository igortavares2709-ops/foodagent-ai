# Política fictícia de reembolso

## Elegibilidade
Reembolsos são apenas simulações. Itens ausentes, cobrança duplicada fictícia
ou pedido não entregue podem ser encaminhados para revisão.

## Segurança
O agente nunca solicita senha, cartão completo, CPF ou chave de API. Dados
pessoais presentes na mensagem devem ser mascarados.
